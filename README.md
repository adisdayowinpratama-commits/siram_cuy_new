# 🌱 SiramCuy — Smart Irrigation & Land Management

**SiramCuy** is a Flutter-based mobile application designed to help users manage agricultural land, discover suitable crops, and organize irrigation schedules in one place.

The application provides a simple and user-friendly interface for recording land conditions, exploring crop recommendations, and keeping track of irrigation activities.

> 🌿 **Manage your land. Find suitable crops. Plan your irrigation.**

## ✨ Features

### 🏠 Home Dashboard

## 🌱 How It Works

1. **Manage your land** — Add the agricultural plots you want to manage.
2. **Analyze land conditions** — Enter the available soil and environmental information.
3. **Explore crop recommendations** — Review the suggested crops and their suitability factors.
4. **Schedule irrigation** — Set the date and time for planned watering.
5. **Track activities** — Review irrigation records to help organize your agricultural activities.

SiramCuy uses manually entered information. It does not require IoT sensors for its core workflow.

---

## 🎯 Project Goals

SiramCuy aims to make basic agricultural land management more organized and accessible through a mobile application. It brings land records, crop suitability information, and irrigation planning together in a single interface.

The project also serves as an implementation of Flutter mobile development, local database management, interface localization, and modular application structure.
